# Independent review of `docs/competitor-study.md` (sections 1–7)

**Reviewer:** independent agent (static re-crawl) · **Date:** 2026-11-10 · **Method:** fresh `curl` fetches of ultion-lock.co.uk and wdlocks.co.uk with a desktop Chrome UA, the public Store API (`/wp-json/wc/store/v1/products?per_page=100`), the live theme stylesheet `app/themes/consultancy/css/style.min.css` (2.2 MB), the theme JS (`js/alpine/locks-product.js`, `js/pages/*.js`, `js/navigation.js`), `page-sitemap.xml`, and the earlier crawl's raw HTML in the scratchpad. No browser was used; no forms submitted, nothing added to a cart.

Overall: the study is **largely accurate**. Of ~95 claims checked, 4 are incorrect, ~8 need nuance, and ~14 are JS/browser-only and could not be verified statically. The bigger issue is **coverage**: the study misses several Ultion pages and mechanics that matter for a rebuild (FAQ accordions, comparison table, crime checker, guarantee-registration form, keycode validation rules, static (not live) Trustpilot, contextual strip variants, sticky/shrinking header, shipping to IE/FR/CI, the `/ultion-alps/` product that shares WD's "ALPS" name, and the fact that WD's homepage copy already paraphrases Ultion's guarantee copy).
